# Description
Provides web get ability for retrieving the content of a given url, getting back either a file containing html, or a file containing the content of the url.

## get\_html
### Description
Given a url, performs an http get and returns a file containing the html content.

### Arguments
*url* The url to fetch<br>
## get\_file
### Description
Given a url, performs an http get and returns a file containing the content.

### Arguments
*url* The url to fetch<br>
