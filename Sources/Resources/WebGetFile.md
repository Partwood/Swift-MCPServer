# Description
Provides web get ability for retrieving the content of a given url, getting back a file containing the content of the url placed in the specified path and given the provided name.
##  get\_file
### Description
Given a url path and name, performs an http get that returns a file containing the content in path with the given name.
### Arguments
*url* The url to fetch
*path* The destination for the file specified by the fetched url
*name* The name of the file
